The best page layout for the moment is as follows:

Body
└──Wrapper
   ├───Header  (menus)
   ├───Content
   │   └───Thin
   │       ├───Header  (preamble of the content)
   │       │   ├───H2 
   │       │   ├───linkbox
   │       │   └───linkbox
   │       └───tables (etc — the actual content)
   └───Footer
       └───P (etc)

Note that H2 is to be replaced by H1
